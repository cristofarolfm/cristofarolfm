# Luis F. M. Di Cristofaro, PhD, B.Pharm.

Pharmacist-scientist with 10+ years of translational oncology research, moving into medical writing, accredited medical education and AI-enabled scientific content.

- **Science:** therapy-induced senescence, DNA damage response, tumor microenvironment, glioblastoma and endometrial cancer; single-cell, spatial and transcriptomic data in R and Python. Co-first author in *EMBO Molecular Medicine* (2025) and author in *Cancer Research* (2021).
- **AI workflows:** I use large language models every day for literature work, drafting and code troubleshooting: Claude, including Claude Code with multiple agents, as well as GPT and DeepSeek. I treat their output as a draft to be checked. Several models cross-check each other, and every claim and reference is verified against the primary source. I once caught a model citing a reference that did not exist.

## Featured project

**[cme-evidence-pipeline](https://github.com/cristofarolfm/cme-evidence-pipeline): draft fast, verify hard**
PubMed and ClinicalTrials.gov retrieval feeds a source-linked evidence table. A constrained prompt has an LLM draft a CME needs assessment, and a verifier that does not use an LLM checks every sentence for fabricated or unrelated citations, numbers that are not in the source, uncited claims and weak support.

- Stress test: 5 of 5 planted errors caught.
- Same prompt run in Claude, ChatGPT and DeepSeek, with results compared side by side.
- Prompt design notes and an iteration log are in [PROMPTS.md](https://github.com/cristofarolfm/cme-evidence-pipeline/blob/main/PROMPTS.md).
